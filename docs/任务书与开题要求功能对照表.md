# 地铁出行指南智能生成系统：任务书/开题要求功能对照表

本文用于答辩展示“要求-实现-证据”闭环，便于快速说明完成度。

## 1. 系统总体目标

- **目标**：基于 LangChain RAG 架构实现地铁出行指南智能生成系统。
- **当前实现说明**：当前版本完成了路线规划、智能指南生成、Web 查询、规则与无障碍数据展示、登录鉴权、历史记录、管理页基础能力。  
  注：RAG 外部大模型联调可作为后续增强（当前指南为规则+算法生成）。

## 3. 本轮新增增强（可作为答辩亮点）

- 智能对比推荐策略：支持 `compare`，自动在最短时间/最少换乘间做解释性推荐。
- 场景化指南：支持通勤、游客、老人/带娃、赶时间四种模式。
- 备选方案并排对比：展示两方案核心指标，便于用户决策。
- 运营状态提示接口：`/api/runtime/status` + 前端状态渲染（演示版，可接实时源）。
- 推荐理由固定展示：结果区独立“智能推荐说明”卡片。
